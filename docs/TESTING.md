# Testing WebSnap

A short guide to send to testers, and a list for you of what to watch.

## For testers (copy this into your message)

> Thanks for trying WebSnap, a free editor that turns screenshots into polished images and store galleries.
> It runs in your browser, nothing is uploaded, and it takes about 10 minutes.
>
> 1. Open the link and click **Open the editor**.
> 2. Drop in a screenshot of something you've made (or any screenshot).
> 3. Try a **template**, then change the background and text.
> 4. Click **New set…** to make a set of 3–5 slides (App Store, LinkedIn carousel, Product Hunt).
> 5. Put a different screenshot on each slide and download the set (**Export slides…**).
>
> Then tell me: Did you get what you wanted? What confused you? What would you need before using it for real work?
> Use the **Feedback** button in the top right, or reply to me directly.

## What to watch while people test

- **Where they get stuck:** the slide strip and **New set…** are new and the likeliest to confuse.
- **Devices and browsers:** ask each tester which one they used. Chrome is tested; Firefox and Safari are not.
- **Video:** MP4 export hasn't been tried in a real browser. Treat any video report as important.
- **Lost work:** designs live in the browser. Ask whether anyone lost something.

## Known limits (be upfront with testers)

- Adding, removing and moving slides can't be undone.
- Store sizes are from memory; check each store's current rules before uploading.
- Share links and screenshot-a-URL are off on the public test site.
- The phone in "phone in front" layouts is always an iPhone.

## Collecting feedback

Feedback button → GitHub issue form ("Tester feedback"). Testers need a GitHub account for that, so also
accept replies by message or email and add them as issues yourself. Label them `feedback`.
